# Уведомления о товарах Wildberries

Telegram-бот проверяет подписку, читает пользовательские фильтры и отправляет карточки товаров с изображением и ценой. Обрабатывает категории, скидки и остатки из базы.

**Стек:** aiogram 3, асинхронный слой базы данных.

## Устройство проекта

- `bot.py` — точка входа.
- `loader.py` — создание клиентов и общих зависимостей.
- `src/database/` — Доступ к данным.
- `src/commands/` — Команды.

## Локальная настройка

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Проверьте `config.py` и параметры, импортируемые в `loader.py`: задайте собственный токен бота, административные ID и необходимые подключения. Храните рабочие секреты вне Git. Если проект использует базу данных, подготовьте её схему и тестовые данные по слою доступа к данным; наличие файла базы в репозитории не означает готовность к эксплуатации.

После настройки зависимостей и конфигурации запускайте из корня репозитория:

```bash
python bot.py
```

## Статус

Исходный проект для изучения асинхронных ботов и разделения обработчиков. Запуск внешних сервисов и production-готовность этой версии не подтверждены. Интеграция зависит от внешних API и структуры данных Wildberries; их актуальная совместимость не проверена.
